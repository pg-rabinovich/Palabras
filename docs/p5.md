# P5 en Palabras

La app usa `p5` en modo instancia para que cada sketch viva dentro de su
componente React sin contaminar `window` ni chocar con otros canvas.

## Estructura

```txt
components/p5/
  p5-canvas.tsx              # wrapper client-only para montar/desmontar p5
  sparks-construccion.tsx    # componente visual reusable

sketches/p5/
  types.ts                   # tipos compartidos
  sparks-construccion.ts     # sketch p5 puro en modo instancia
```

## Como crear un sketch

Crear un archivo en `sketches/p5/`:

```ts
import type { P5Sketch } from "./types"

export const miSketch: P5Sketch = (p, contexto) => {
  p.setup = () => {
    const { ancho, alto } = contexto.obtenerTamano()
    p.createCanvas(ancho, alto)
  }

  p.draw = () => {
    p.clear()
    p.circle(p.width / 2, p.height / 2, 20)
  }

  p.windowResized = () => {
    const { ancho, alto } = contexto.obtenerTamano()
    p.resizeCanvas(ancho, alto)
  }
}
```

Luego crear un componente en `components/p5/`:

```tsx
"use client"

import { P5Canvas } from "@/components/p5/p5-canvas"
import { miSketch } from "@/sketches/p5/mi-sketch"

export function MiSketch() {
  return <P5Canvas sketch={miSketch} className="absolute inset-0" />
}
```

## Convertir p5 global a instance mode

Codigo original:

```js
function setup() {
  createCanvas(windowWidth, windowHeight, WEBGL)
}

function draw() {
  background("#050505")
}
```

Version para la app:

```ts
export const sketch: P5Sketch = (p) => {
  p.setup = () => {
    p.createCanvas(p.windowWidth, p.windowHeight, p.WEBGL)
  }

  p.draw = () => {
    p.background("#050505")
  }
}
```

Regla practica: casi todo es igual, pero agregando `p.` delante de las funciones
y constantes de p5.
